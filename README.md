# To-Do Pro

Aplicação React para organização de tarefas. Permite que você organize suas tarefas as criando e alterando seu estado de "Pendente" para "Concluída.

## Pré-requisitos
- Node.js LTS
- npm

## Clonando o repositório

Copie o endereço do repositório e o cole em frente ao seguinte comando no terminal:

```bash
git clone <link do repositório>
```

## Instalação

Abra a pasta do repositório no terminal e execute o seguinte comando:

```bash
npm install
```

## Execução

Para executar o programa utilize o seguinte comando no terminal:

```bash
npm run dev
```
